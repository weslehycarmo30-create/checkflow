# Piloto Wesley 001 — configuração recomendada

Documento manual; não autoriza escrita remota.

| Campo | Recomendação |
| --- | --- |
| Organização | Piloto Wesley 001 |
| Pessoas | 1 owner; 1 manager apenas se necessário; 1–3 collaborators |
| Unidade | uma única unidade inicial |
| Templates | máximo 5; os 5 já vêm prontos em **Modelos** (Abertura do bar, Operação do evento, Conferência de bebidas e insumos, Fechamento do bar, Buffet) |
| Primeiro evento | 3 checklists: Abertura do bar, Operação do evento e Fechamento do bar, criados pelo botão “Usar modelo” |
| Atribuição | um executor por checklist |

Antes de começar, owner e executor confirmam organização e atribuição. Use dados não sensíveis e siga o console de suporte para qualquer falha.

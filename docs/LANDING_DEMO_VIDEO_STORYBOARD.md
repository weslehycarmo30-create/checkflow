# CheckFlow — storyboard da demonstração comercial

Vídeo futuro: 30–45 segundos, sem autoplay e otimizado para web.

| Tempo | Cena | Overlay |
|---|---|---|
| 0–5s | Visão do gestor | ACOMPANHE |
| 5–10s | Atribuição de uma rotina | ATRIBUA |
| 10–18s | Execução mobile | EXECUTE |
| 18–24s | Evidência/foto | COMPROVE |
| 24–30s | Não conformidade | CORRIJA |
| 30–36s | Ação corretiva | CORRIJA |
| 36–42s | Conclusão e histórico | ACOMPANHE |
| 42–45s | Marca CheckFlow | CheckFlow |

Gravar apenas fluxos e dados demonstrativos aprovados; não usar dados de clientes.

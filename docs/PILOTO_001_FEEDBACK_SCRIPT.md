# Piloto 001 — roteiro de feedback

Conversa de 8–10 minutos após o turno. Não registrar senhas, fotos, respostas privadas ou dados de clientes.

1. O que ficou mais fácil?
2. O que ficou mais demorado?
3. Onde você se confundiu?
4. Voltaria para WhatsApp/papel? Por quê?
5. Qual checklist mais ajudou?
6. Qual parte você não usaria?
7. Que problema ainda não resolvemos?
8. Pagaria para continuar usando?
9. Quanto valor isso gerou na operação?

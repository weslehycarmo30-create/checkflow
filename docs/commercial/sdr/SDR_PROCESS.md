# Processo SDR CheckFlow

`RAW LEAD → RESEARCHED → QUALIFIED → PRIORITY → CONTACT READY → CONTACTED → REPLIED → DIAGNOSIS → DEMO → PROPOSAL → PILOT → PAID / LOST`

| Estágio | Critério objetivo de entrada | Próximo passo |
| --- | --- | --- |
| RAW LEAD | nome e fonte, sem validação | pesquisa leve pública |
| RESEARCHED | segmento, cidade e sinais registrados | aplicar score |
| QUALIFIED | score ≥50 e operação compatível | conferir decisor/canal |
| PRIORITY | score ≥65 ou indicação | personalizar gancho |
| CONTACT READY | mensagem e próxima ação prontas | contato humano |
| CONTACTED | primeira mensagem enviada e data registrada | cadência D2 |
| REPLIED | resposta recebida | diagnosticar, não vender ainda |
| DIAGNOSIS | dor/processo/equipe entendidos | decidir SQL e agendar demo |
| DEMO | demo marcada ou realizada | proposta clara |
| PROPOSAL | escopo/preço/data enviados | follow-up combinado |
| PILOT | aceite e onboarding iniciado após gates técnicos | acompanhar D0–D14 |
| PAID | contratação/renovação confirmada | suporte e indicação |
| LOST | sem fit, sem timing ou recusou | motivo e data de recontato |

Não mover por “sensação”: registre fato, fonte, data e próxima ação. Não contate sem mensagem personalizada e canal público/autorizado.

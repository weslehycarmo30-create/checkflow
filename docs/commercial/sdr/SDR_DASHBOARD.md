# Dashboard manual SDR

Atualizar uma vez por dia usando `checkflow_prospects.csv`.

| Indicador | Fórmula |
| --- | --- |
| Leads pesquisados | total RESEARCHED ou posterior |
| Qualificados | QUALIFIED ou posterior |
| HOT | score 80–100 |
| Contatados | CONTACTED ou posterior |
| Respostas | REPLIED ou posterior |
| Diagnósticos | DIAGNOSIS ou posterior |
| Demos | DEMO ou posterior |
| Propostas | PROPOSAL ou posterior |
| Pilotos | PILOT |
| Pagos | PAID |
| Response rate | respostas / contatados |
| Contact → diagnosis | diagnósticos / contatados |
| Diagnosis → demo | demos / diagnósticos |
| Demo → proposal | propostas / demos |
| Proposal → paid | pagos / propostas |

Use números absolutos e taxa; não conclua causalidade com amostra pequena.

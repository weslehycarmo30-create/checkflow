# Precificação da beta assistida

| Opção | Vantagem | Risco | Uso |
| --- | --- | --- | --- |
| A — R$49,90/mês | entrada muito fácil | não remunera suporte manual | somente teste de demanda muito curto |
| B — R$79,90/mês | sinaliza B2B acessível | ainda exige limite claro de suporte | plano simples após beta |
| C — setup + mensalidade | remunera implantação | atrito inicial maior | melhor quando há configuração real |
| D — fundadores | urgência e aprendizado | pode ancorar preço baixo | primeiros 3, prazo limitado |

## Recomendação

**Fundadores: R$149 de setup + R$79,90/mês**, preço protegido por 3 meses, cancelamento simples e limite de uma unidade/8 usuários/5 templates. Para reduzir atrito, o setup pode ser convertido em crédito no segundo mês se o cliente concluir o onboarding. Não ofereça “ilimitado”.

R$49,90 é barato demais para suporte assistido; R$79,90 sozinho funciona após o processo estar repetível. Reavaliar preço somente após os três primeiros clientes e registrar horas reais de suporte.

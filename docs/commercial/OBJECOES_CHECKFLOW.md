# Objeções frequentes

| Objeção | Resposta curta |
| --- | --- |
| “Já uso WhatsApp.” | WhatsApp cobra, mas não deixa histórico por item, evidência e responsável num só lugar. |
| “Já uso papel.” | O papel funciona até você precisar saber quem fez, o que falhou e se resolveu. |
| “Funcionário não vai usar.” | Começamos com uma rotina curta no celular e treinamos na primeira execução. |
| “É caro.” | O teste custa menos que uma falha repetida de abertura ou estoque; medimos valor em 14 dias. |
| “Não preciso disso.” | Se hoje tudo é conferido e resolvido sem retrabalho, não faz sentido. Onde isso falha? |
| “Não quero outro sistema.” | Não é para trocar tudo: começa em uma rotina que já existe. |
| “Posso usar Google Forms.” | Pode; CheckFlow acrescenta atribuição, ciclo, NC, plano e histórico operacional. |
| “E sem internet?” | Não prometemos operação offline; definimos registro manual de contingência para o turno. |
| “E minhas fotos/dados?” | Uso é operacional, acesso é por empresa e formalizamos privacidade/retenção antes de contratar. |

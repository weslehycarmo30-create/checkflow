# Cliente 002 — perfil ideal

| Tema | Perfil prático |
| --- | --- |
| Negócio | Bar/restaurante independente, buffet ou equipe de eventos com 5–20 pessoas. |
| Decisor | Dono presente, gerente operacional ou responsável de eventos. |
| Dor | Abertura/fechamento inconsistentes, falta de estoque, equipe sem retorno e problemas descobertos tarde. |
| Sinais de compra | Usa grupo de WhatsApp para cobrar tarefas; tem recorrência de evento; reclama de desperdício/falhas; aceita teste no celular. |
| Onde encontrar | Rede de Wesley, fornecedores, eventos locais, visitas presenciais e indicações — sem lista comprada. |
| Abordagem | “Posso te mostrar em 10 minutos como transformar a abertura em registro com responsável e foto?” |
| Objeções | Tempo da equipe, preço, internet, “já uso WhatsApp/Formulários”. |

Evitar: rede grande, franquia, operação sem decisor acessível, exigência de integração ou cliente que pede software sob medida antes de testar.

# Catálogo comercial inicial

| Template | Melhor uso | Itens-chave | Evidência/NC |
| --- | --- | --- | --- |
| Abertura do Bar | início de turno | higiene, gelo, estoque, equipamentos | NC/foto para risco e falta |
| Fechamento do Bar | fim de turno | contagem, limpeza, equipamentos, chaves | NC para divergência; sem valores sensíveis |

| Limpeza de Estação | diário | superfícies, pia, lixo, utensílios | NC/foto de não conformidade |
| Recebimento | entrega | nota, temperatura, embalagem, validade | NC/foto de avaria |
| Segurança Alimentar | rotina | higiene, contaminação, temperatura | NC crítico e foto autorizada |
| Geladeira/Freezer | abertura/fechamento | temperatura, porta, vedação, organização | NC se fora do padrão local |
| Pré-evento | antes do serviço | equipe, materiais, layout, cronograma | NC para ausência impeditiva |
